# Theme: GS Construction (`gsc`)

Intentionally **empty**. gs.construction renders from `resources/views/` directly; the
overlay falls through when a theme defines no override.

Put a file here only to change gs.construction *without* affecting the shared fallback
other sites inherit. In practice, GS-specific edits still go in `resources/views/`.

Brief: `docs/sites/gsc.md`
